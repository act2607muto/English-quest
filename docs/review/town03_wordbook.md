# 3つ目の街の「単語の書庫」800語（見てもらう用）

書庫のモンスター：**じびきモグラ**（HP 200、20G）。分厚い字引の中にトンネルを掘ってくらすモグラ。掘り出した単語を、鼻先でくるりとめくって読んでみせる。

気になる単語（意味がちがう・むずかしすぎる・やさしすぎる など）があれば、英語を教えてください。

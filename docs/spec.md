# 英語ステータス育成アプリ 仕様書（アプリ名：English Quest）

2026-11-15 時点

## 概要

自分の英語力を6つの能力値の六角形として育てる、ドラクエ風のWebアプリを作る。街を拠点に、英語の問題を解いてモンスターを倒し、経験値とお金を得て装備を整え、次の街へ進む。練習すると六角形が広がり、放置するとしぼむ。

作る理由は、既存の英語アプリは飽きるがゲームは続くから。ドラクエのレベル上げの感覚を、英語の練習にそのまま持ち込む。

既存アプリとの違いは3つ。

- 育てる対象はモンスターや仲間ではなく自分自身。
- 能力値が技能ごとに分かれ、得意と苦手が形で見える。
- 教材を自分で足せるので、覚えたい内容だけで遊べる。

## 成長の仕組み

能力値はそれぞれ経験値を持ち、経験値からレベル1〜99が決まる。練習した能力値だけが伸び、練習しない能力値は下がる。数値はすべて初期値で、遊びながら調整する。

### 経験値の入り方

| 出来事 | 経験値 |
| --- | --- |
| 正解、またはAI採点で「通じる」 | 10 |
| AI採点で「惜しい」 | 5 |
| 復習の時期が来ていた問題に正解 | 15 |
| 不正解、またはAI採点で「通じない」 | 0（減点はしない） |
| ミスなしで戦闘に勝つ | 追加で合計10。出た能力値に同じだけ分け、合計が10を下回らないよう切り上げる（1種類10、2種類5ずつ、3種類4ずつ、4種類3ずつ、5〜6種類2ずつ。2026-11-17 本人が決定） |

### レベル

- レベルに必要な累計経験値は「30 ×（レベル − 1）の2.5乗」。王道のRPGのように、レベル2はすぐ上がり、上がるほど次のレベルまでの経験値が大きく増える。
- 目安は、レベル2が正解3問、レベル3が17問、レベル5が96問、レベル10が729問、レベル20が4,721問。
- 総合レベルは、解放済みの能力値のレベルの平均（小数切り捨て）。
- 総合レベルの節目で称号が変わる。

### 能力値の低下

- その能力値を最後に練習してから3日間は下がらない。
- 4日目から、1日ごとに経験値が1%ずつ減る。
- 下限は、その能力値の過去最高経験値の70%。それ以上は下がらない。
- 例：レベル30の能力値を1か月放置するとレベル27になり、最低でもレベル26で止まる。

### 復習の出し方

- 問題ごとに次の復習日を持たせる。正解するたびに間隔が1日、3日、7日、14日、30日と延びる。
- 不正解なら1日に戻る。
- 復習日より前に正解しても、間隔は延ばさない（同じ日に何度も正解して、一気に30日先まで飛ばないようにする）。
- 練習では、復習日が来た問題を先に出し、残りを新しい問題で埋める。

### 六角形の見せ方

- 実線が現在のレベル、点線が過去最高。下がった分がすき間として見える。
- 目盛りの上限は10、25、50、99と段階的に広げる。序盤でも六角形が小さく見えすぎない。

## 冒険の仕組み

街を拠点に、街の外でモンスターと戦い、得たお金で装備を買い、ボスを倒して次の街へ進む。進む手段は問題を解くことだけにする。

1. 街で、戦う相手と装備を選ぶ。
2. 街の外でモンスターと戦う。問題に正解すると攻撃になる。
3. 勝つと経験値とお金が入り、能力値が伸びる。
4. お金がたまったら、店で武器や防具を買う。
5. 街の問題を十分に解いたらボスに挑む。勝つと次の街へ進める。

### 街

- 街1つが会話の場面1つ。最初の街は「はじまりの街」（あいさつと自己紹介）。
- 2つ目の街は「にぎわいの市」（買い物、難しさ「標準」。2026-11-18 本人が決定）。1つ目より一段上（中学2〜3年、TOEIC 500〜600 くらい）で、リーディングがこの街で解放される。教材は6つの能力値を30問ずつ（180問）。
- 次の街の候補は、買い物、食事、道案内、予定の相談、雑談。先の街ほど問題が難しくなる。
- 3つ目の街は「みちしるべの宿場町」（食事と道案内、2026-11-21 本人が決定）。教材は6つの能力値を60問ずつ（360問）、書庫は800語。この街から単語の並べかえ（文法）と2人の会話のリスニングが加わる。ボスはすぎ並木の先の「まよいの分かれ道」にいる、みちまよいの大ダコ。
- 街には、街の外への出口、スキルダンジョン、店、自分のステータスがある。ボスは街の外のマップの奥（最初の街は、ささやきの森の奥「ことだまの門」）にいて、歩いてそこへ行く（2026-11-17 本人が決定）。

### 旅の地図（2026-11-21 本人が決定）

- 街を「点」、街どうしを「道」でつないだ世界地図。行ったことのある街を押すと「〇〇へ 向かいますか？」と聞き、すぐにその街へ移る（移り方は門やマップの端の道と同じ）。まだ行っていない街は「？？？」と出す。
- 最初から行き来できると味気ないので、3つ目の街に着いたときに「旅の地図を手に入れた！」と知らせ、そこから街の画面の右上と、冒険のマップの下（「▶ 旅の地図」）に地図のボタンを出す。冒険のマップから開いたときは「▶ 冒険にもどる」で、同じ場所にもどる。
- 「行ったことのある街」は記録からわかる：1つ目の街、今いる街、1つ前の街のボスを倒した街。
- 地図のファイルは public/maps/world.json（背景の絵 world.png・使えるようになる街の順番 unlock_order・街の点の位置・道）。街を足すときは、ここに点と道を足す。処理は src/lib/game/worldMap.ts、画面は screens/WorldMapScreen.tsx。
- 管理者は、設定の「デバッグ用：旅の地図」で、3つ目の街に着く前でも地図のボタンを出せる（その端末だけ）。

5つ目の街を一旦の最後にし、そこで TOEIC 800 くらい（CEFR B2）に届くようにする。問題数は案3（先の街ほど大きく＋単語の書庫）。

|---|---|---|---|---|---|
| 1 はじまりの街 | あいさつ・自己紹介 | 中1・TOEIC 300〜400 | 150 | 400（中学の基本） | 基本の5つの能力値 |
| 2 にぎわいの市 | 買い物 | 中2〜3・TOEIC 500〜600 | 180 | 600 | リーディング |
| 3 | 食事と道案内 | 高1・TOEIC 600〜650 | 360（6×60） | 800 | 単語の並べかえ、2往復の会話を聞く |
| 4 | 予定の相談・電話・雑談 | 高2・TOEIC 650〜720 | 480（6×80） | 1,000 | 書き取り、メールやメッセージを読む |
| 5（最後） | 旅行と仕事 | 高3〜大学・TOEIC 750〜800 | 600（6×100） | 1,200 | アナウンスや説明を聞く、意見や理由を話す・書く |

- 合計：問題 約1,770問＋書庫の単語 4,000語（TOEIC 800 に要ると言われる 6,000〜8,500語のうち、よく出る部分）。
- 文法の割りふり：3 は未来（will / be going to）・助動詞・過去進行形・場所と方向の前置詞、4 は現在完了の使い分け・関係詞・分詞・使役・仮定法過去・句動詞、5 は仮定法過去完了・分詞構文・ていねいな頼み方と言いかえ・ビジネスの決まった言い方。
- 聞く力：一文（1〜2）→ 2往復の会話（3）→ 電話や少し長い会話（4）→ アナウンスや説明（5）。読む力：張り紙・メモ（2）→ メニュー・案内（3）→ メール（4）→ 記事・複数の文書（5）。
- モンスターの HP・お金・武器は街ごとに少しずつ上げる。5つ目の街のボスを倒したら、エンディングのお知らせを出す。

### 単語の書庫（2026-11-21）

- スキルダンジョンの中の部屋。書庫のモンスター（ID の最後が -wordbook）と戦うと、その街の書庫の単語だけが4択で出る（「「英語」の意味は？」）。
- 単語の一覧（英語・品詞・意味・例文）は scripts/wordbook/{街のID}.mjs に書き、scripts/build_wordbook.mjs で data/{街のID}_wordbook.json（書庫のモンスター＋問題）を作って取り込む。問題には tags に "wordbook" をつける。
- 一覧は、よく使われる英語の単語から作ったオリジナル。市販の単語帳の並びや例文は写さない。まちがいの選択肢は、同じ品詞のほかの単語の意味から選び、意味が重なるものは選ばない。
- 書庫の単語は、街の外のモンスター・ボス・復活モンスター・ボスの目安（問題の8割）には入れない。復習の時期が来た単語は、書庫の戦闘で先に出る。
- 正解の経験値は少なめ（語彙に 4、復習の時期の単語は 6）。スキルダンジョンの書庫のカードに「覚えた単語 N / 全部」と「復習 N語」を出す。
- 街1〜2の単語を先に作り、本人に一部を見てもらいながら、街ごとに足していく。街1＝しおりオバケ（400語、中学の基本）、街2＝ふせんチョウ（600語、中2〜高1・買い物の単語を多めに。街1と同じ単語は入れない）。街3＝じびきモグラ（800語、高1・TOEIC 600〜650。食事と道案内の単語が3分の1ほど、ほかは高校で習う動詞・名詞・形容詞・副詞。街1・2と同じ単語は入れない。2026-11-21）。

### 戦闘

| 項目 | 内容 |
| --- | --- |
| 相手の選び方 | 街の外のマップを歩き、草むらなどでモンスターに出会う（場所ごとに出やすい能力値が違う。苦手な能力値・下がり始めた能力値ほど出やすい。復習の時期が来た問題があれば、ときどき復活モンスターになる）。練習したい能力値を自分で選んで戦いたいときは、街の「スキルダンジョン」へ行く。モンスターの種類が能力値に対応し、倒すとその能力値が伸びる |
| 攻撃 | 正解、またはAI採点で「通じる」「惜しい」なら、相手に攻撃力ぶんのダメージ |
| 攻撃力 | 総合レベル1のとき6。総合レベルが1上がるごとに+3。その能力値の武器を装備していれば上乗せ（最初の街の武器は+2か+3。すべての能力値に効く武器もある）。どんなに強くても、倒すには最低2回の正解が要る |
| 被ダメージ | 不正解、または「通じない」なら、自分が1ダメージ |
| 相手のHP | モンスターごとに変える。最初の街は ページムシ40、つみきゴーレム60、おおみみ50、インクつぼ40、おしゃべりどり30、ボスは100（攻撃力9なら、それぞれ5・7・6・5・4・12回の正解で倒せる）。モンスターのファイルの `hp` で決める |
| 自分のHP | 基本は3。総合レベル10ごとに1増える。戦闘のたびに全回復する |
| 勝ったとき | 経験値とお金を得る。お金はモンスターごと（最初の街は8〜12。HPが多いほど多い）、復活モンスター15、ボス100、こばんガエル80 |
| 負けたとき | 街に戻る。正解した分の経験値は残り、お金は入らない。失うものはない |

- 復習の時期が来た問題は「復活モンスター」として街の外に現れる。倒すと経験値とお金が多めに入る。
- 復活モンスターは、もとのモンスターの色違い（2026-11-17 から、薄紫と水色の色違いの絵 `{もとの名前}-revival.png` を使う。絵がなければ画面で色をずらす）。HPは「もとのHP」と「復習の時期が来た問題の数だけ正解すると倒せるHP」の小さいほうで、復習の問題を先に出す。
- めずらしいモンスター（2026-11-17 本人が決定）：街の外のマップでだけ、まれに出会う。ボスと同じように、今戦えるすべての能力値の問題を交互に出す。スキルダンジョンには出ない。「もう一度戦う」はない。
  - ひらめきボタル：出会いの1%。HP 30、お金10G。勝つと経験値のおまけ300を、その戦闘で出た能力値で分けて足す（5つ出たら60ずつ）。
  - こばんガエル：出会いの4%。HP 40、お金80G。
- ボスにはいつでも挑める（2026-11-18 本人が決定。英語が得意な人が待たされて離れないように）。その街の問題の8割に1回以上正解するのは「おすすめの目安」として、ボスの画面と街の画面に出す。出題はその街で練習した能力値の混合（まだ練習していなければ、戦えるすべての能力値）。
- ボスの100 Gは、最初に倒したときだけ。2回目からは10 G（何度も倒してお金をためられないようにする）。
- 最初の街のボスは「ことだまの門番」、2つ目の街は東の関所の「せきもりの大ガメ」（どちらも96×96のドット絵）。
- 街の行き来（2026-11-18 本人が決定）：ボスを倒すと、ボスの画面に「門をくぐって次の街へ」が出る（順番が次の街。まだなければ「準備中」）。前の街へは、マップの端の道（tiles の "exit": 街のID）を踏み、「向かいますか？」に答えて戻る。世界地図は作らない。
- 新しい街に着くと、その街に問題がある能力値のうち未解放のもの（リーディング）を解放し、街の画面に「着いた！」と出す。総合レベルは、まだ一度も練習していない能力値を除いて計算する（着いたとたんに下がらないように）。
- ボスとめずらしいモンスターが出す能力値は、その街に問題がある能力値の中から選ぶ。
- 練習回数を制限するスタミナは入れない。何戦でも続けられる。
- 数値はすべて初期値で、遊びながら調整する。

### お金と装備

- 装備できるのは武器1つと防具1つ。街の店で買い、いつでも付け替えられる。
- 武器は、特定の能力値の問題に正解したときの攻撃力を上げる。例：語彙の問題で攻撃力が2上がるナイフ。戦うモンスターに合わせて持ち替える。高い武器には、どの能力値の問題でも攻撃力が上がるものもある。
- 防具は、自分のHPを1増やすか、能力値が下がり始めるまでの猶予を1日延ばす。
- 装備は英語の正誤を変えない。ヒントを出す、選択肢を減らすといった効果は入れない。
- 第1段階の店には、武器6つ（能力値ごとに1つと、すべてに効く1つ）と防具2つを置く（2026-11-17 本人が決定）。
  - 武器：ことのはのナイフ（語彙+2）70G、くみたてハンマー（文法+2）70G、みみすましの弓（リスニング+3）100G、よびかけの杖（スピーキング+3）100G、はねペンのつるぎ（ライティング+3）120G、たびだちのつるぎ（すべて+3）300G（2026-11-18 に「にじいろのつるぎ」から改名。2つ目の街の「いちばの大剣」より強そうに見えたため、絵も地味な鉄の剣にした）
  - 防具：たびびとのマント（HP+1）150G、わすれずのかぶと（低下まで+1日）250G
- ガチャは入れない。

### 見た目

- 絵はドット絵で、Pixellab で作る（2026-11-16 に決定）。輪郭は黒1色、背景は透明（街の背景を除く）。
- 大きさは、モンスターと主人公が64×64、ボスが96×96、装備品が32×32、街の背景が256×112。画面には元の大きさの整数倍で出す（モンスターは一覧64px・戦闘128px、ボスは192px）。
- モチーフは能力値を連想できるものにする。語彙は本、文法は積み木のゴーレム、リスニングは耳の大きな生き物、ライティングは羽ペンつきのインクつぼ、スピーキングはくちばしの大きな鳥。
- 画面は、文字のコマンドと小さな絵を組み合わせる。
- 第1段階に必要な絵は、主人公1、モンスター5、めずらしいモンスター2、ボス1、街の背景1、工房の絵1、装備品8。復活モンスターや先の街の強い敵は色違いで表す。
- 絵は `public/` の下に PNG で置く。描き直すときは、同じ名前の PNG を置き換える。前の仮の絵を作った `scripts/make_sprites.mjs` は、実行すると今の絵を上書きするので使わない。街の背景は、街のファイルの `town.background_image` に書く。
- 名前とデザインはすべてオリジナルにする。

## 練習メニュー

練習はすべて戦闘の形で行う。第1段階で語彙・文法・リスニング・スピーキング・ライティングの5つを動かす。スピーキングとライティングはAIが採点する。

| 能力値 | 練習内容 | 判定方法 | 作る手間 | 導入 |
| --- | --- | --- | --- | --- |
| 語彙 | 英単語の意味を4択で選ぶ。日本語から英単語を入力する | 正解との一致 | 小 | 第1段階 |
| 文法 | 穴埋めを4択で選ぶ。単語を正しい順に並べる | 正解との一致 | 小 | 第1段階 |
| リスニング | 音声を聞いて意味を4択で選ぶ。聞いた文を書き取る。音声は自動では流さず「▶ 聞く」を押して流す（何度でも聞ける。2026-11-18）。声は端末にある英語の声からいちばん自然なものを選ぶ（Windows の Edge は Microsoft の Natural の声、Chrome は Google の声、iPhone は Samantha など。Windows に最初から入っている Zira などは、ほかにないときだけ。2026-11-21）。設定の「音」に、今の声の名前と「聞いてみる」を出す | 正解との一致 | 小〜中。音声はブラウザの読み上げ機能で出す | 第1段階 |
| ライティング | 日本語の文を英訳して入力する | AIが3段階で採点して助言を返す | 中。AI採点の仕組みが要る | 第1段階 |

| リーディング | 短い文章（お知らせ・メモ・レシート・短い会話）を読み、内容についての質問に4択で答える。文章は sentence に改行つきで書き、戦闘ではほかの問題の英文と同じ金色の字で、改行どおりに出す | 正解との一致 | 中。文章と設問の用意に手がかかる | 2つ目の街から |

未導入の能力値は、六角形の上で「未解放」として表示する。総合レベルが一定に達すると解放される演出にすると、開発の順番がそのままゲームの進行になる。

問題はアプリに固定せず、ファイルから取り込める形にする。覚えたい単語や文を後から自由に足せる。

### スピーキングとライティングのAI採点

声で答えた内容を文字にしてAIに送り、3段階の評価と助言を受け取る。

1. 日本語の文、または英語の質問を表示する。
2. 録音ボタンを押して声で答える。
3. 録音した音声をサーバー経由でAIの文字起こしに送り、文字にする。
4. 文字になった答えを確認する。聞き取りが違っていれば手で直せる。
5. 答えと模範解答をAIに送る。
6. AIが「通じる」「惜しい」「通じない」の評価、一言の助言、より自然な言い方を返す。

- 採点するのは意味、文法、自然さ。発音そのものは採点しない。文字起こしが正しく聞き取れたかどうかが発音の目安になる。
- 英語の質問に答える問題（respond）では、模範解答は一例として扱う。答えの中身（仕事、住んでいる所など）が模範解答と違っても、質問に合った答えで文法が正しければ「通じる」とする。
- ブラウザ標準の音声認識は使わない。iPhoneでホーム画面に追加して開くと動かないという報告がある。録音して送る方式ならブラウザを選ばない。
- 通信できないときや録音が使えないときは、模範解答を見て自分で「言えた／言えなかった」を選ぶ自己採点に切り替える。

ライティングは、入力した英文をそのままAIに送る。評価と助言の返し方はスピーキングと同じ。

### 教材の方針

教材は日常会話を題材にし、今のレベルからTOEIC 750点相当まで3段階の難易度で用意する。

- 題材は場面別にする。あいさつ、買い物、食事、道案内、予定の相談、雑談など。
- 難易度は「基本」「標準」「目標」の3段階。基本は簡単な単語と短い文、目標はTOEIC 750点相当。
- 総合レベルが上がるにつれて、出題の難易度も上がる。
- 単語は単体で出さず、会話で使う例文と一緒に出す。
- TOEIC（L&R）は聞く力と読む力の試験。点数が上がっても話す力は別に鍛える必要があるため、スピーキングを第1段階から入れる。

問題はAIに作らせる。

- 場面と難易度を指定して、問題をまとめて作らせる。
- 作った問題は自分で目を通してから取り込む。AIは誤った正解や不自然な例文を出すことがある。
- 練習中におかしい問題を見つけたら、その場で印をつけて後で直せるようにする。
- 第1段階は、アプリの外で作ったファイルを取り込む。アプリの中で問題を作る機能は第2段階で足す。

### 音（2026-11-20）

- 音のファイルは使わず、Web Audio で合成する（src/lib/sound.ts）。昔のゲーム機のような音。Pixellab の音楽・効果音は Tier 2 からなので使っていない。あとで音のファイルにするときは sound.ts だけを直す。
- BGM は4曲（街・街の外・戦闘・ボス）。どれもこのアプリのためのオリジナルのメロディで、8小節をくり返す。結果の画面とマイクのテストでは止める。
- 効果音：ボタン、モンスターが現れたとき、正解（斬る音）、まちがい（ダメージ）、モンスターを倒したとき、勝ち・負け、レベルアップ、工房で買ったとき、街を移るとき。
- iPhone では最初に画面にさわるまで鳴らない。マナーモードのときも鳴らない。リスニングの読み上げ中と録音中は BGM を消す。

## データ設計

保存するデータは8種類。教材、ゲームの設定（街・モンスター・装備品）、自分の記録の3つに分けて持ち、教材や設定を入れ替えても記録が壊れないようにする。

| データ | 主な項目 | 用途 |
| --- | --- | --- |
| 問題 | ID、街、能力値の種類、出題形式、問題文、選択肢、正解、解説、難易度、タグ、要修正の印 | 出題の元データ |
| 街 | ID、名前、会話の場面、難易度、順番、背景の絵 | 世界の構成 |
| モンスター | ID、名前、街、能力値の種類、HP、もらえるお金、ボスかどうか、絵 | 戦闘の相手 |
| 装備品 | ID、名前、武器か防具か、効果、価格、売っている街、絵 | 店の品ぞろえ |
| 問題ごとの学習状態 | 問題ID、復習間隔の段階、次の復習日、正解数、不正解数、最後に答えた日、直近の答えとAIの助言 | 復習の出し分け、ボスに挑めるかの判定 |
| 能力値 | 種類、現在の経験値、過去最高の経験値、最後に練習した日、解放済みかどうか | 六角形とレベル、低下の計算 |
| 冒険の状態 | 主人公の名前と見た目（hero_look：boy・girl）、現在の街、所持金、持っている装備、装備中の武器と防具、倒したボス | 進行状況 |
| 戦闘の履歴 | 日時、モンスター、問題数、正解数、勝敗、獲得した経験値とお金 | 記録画面 |

- すべてサーバーのデータベースに保存し、どの端末からも同じ記録を使う。
- 能力値の低下は毎日動かす処理にしない。アプリを開いたときに「最後に練習した日」から計算する。
- 後から公開できるよう、自分の記録には最初から利用者IDの欄を持たせる。自分専用の間は1人分でよい。
- 問題は、AIに作らせたJSONファイルを取り込んで登録する。街、モンスター、装備品も同じくファイルで用意し、街を足すときにプログラムを直さずに済むようにする。

### 問題ファイルの形式

最初の街の教材は150問で、語彙・文法・リスニング・ライティング・スピーキングが30問ずつ。1つのJSONファイル（`data/town01_questions.json`）にまとめてある。2つ目の街は180問（リーディングを足して6つ×30問、`data/town02_questions.json`。作り直しは `node scripts/build_town02.mjs data/town02_questions.json`）。街の情報（town）には name（街の名前）も書ける。

| 項目 | 内容 |
| --- | --- |
| id | 問題のID。例：town01-voc-001 |
| town | 街のID |
| skill | 能力値。vocabulary、grammar、listening、writing、speaking |
| format | 出題形式。choice4（4択）、translate（日本語を英語にする）、respond（英語の質問に答える）、order（単語の並べかえ。3つ目の街から）、dictation（書き取り。4つ目の街から） |
| prompt | 画面に出す指示文 |
| sentence | 出題する文。文法は空欄つきの英文、ライティングは日本語、respondは英語の質問 |
| sentence_ja | respondの質問の日本語訳（画面には出さない。AI採点で質問の意味として使う。2026-11-22）。orderでは画面に出す日本語（この意味になるように並べる） |
| audio_text | リスニングで読み上げる英文。画面には出さない。会話は1行に1人ずつ「A: 英文」の形で書くと、話す人ごとに声を変えて読む（3つ目の街から） |
| choices、answer | 4択の選択肢と、正解の位置（0から数える）。orderでは choices に並べる単語のカードを書き、answer は書かない |
| model_answers | AI採点に渡す模範解答。複数入れられる。orderでは正しい英文（並べ方が2通りあれば2つ。1つ目を正解として見せる） |
| explanation | 答えたあとに見せる解説 |
| difficulty、needs_fix | 難易度と、要修正の印 |

- 文中の `{{name_ja}}`（日本語のフルネーム）、`{{given_ja}}`（日本語の下の名前）、`{{name_en}}`（英語のフルネーム）、`{{given_en}}`（英語の下の名前）は、出題するときに本人の名前に置き換える。名前は設定画面で入れ、未設定の間は「田中ユキ／Yuki Tanaka」で出す。
- 選択肢は、画面に出すたびに並びを混ぜる。ファイル上の正解の位置が偏っていても、出題では偏らない。
- 単語の並べかえ（order、2026-11-21）：カードには文の終わりの . ? ! を入れず、文の最初の単語も名前と I のほかは小文字で書く（大文字がヒントにならないように）。終わりの記号は画面で最後に決まった記号として出す。答え合わせは大文字・小文字と . , ! ? を無視して、model_answers のどれかと同じなら正解（AI採点はしない）。取り込みでは、model_answers がカードと同じ単語でできているかを確かめる。データベースに order を足す SQL は supabase/migrations/20261121000000_word_order.sql。
- 書き取り（dictation、2026-11-21）：audio_text を読み上げ（「▶ 聞く」と「▶ ゆっくり聞く」）、聞こえた英文を書く。model_answers の1つ目は audio_text と同じ英文にし、数字を文字でも書けるときなどは足す。答え合わせはアプリの中でする（src/lib/game/dictation.ts）：大文字・小文字、. , ! ?、よく使う短縮形（I'm と I am、' の打ち忘れの Im・dont など）のちがいは無視し、同じなら正解、4語以上の文で1語だけちがえば「惜しい」（it's を its と書いたときも惜しい）。答えたあとは、正しい英文のうち書けていなかった単語を赤で示す。SQL は supabase/migrations/20261121010000_dictation.sql。
- 意見と理由（5つ目の街から、2026-11-22）：respond の問題の tags に opinion をつける（ライティングでもスピーキングでも使える）。AI採点では、意見がはっきりしていて理由が1つ以上あれば good、理由がなければ close（意見の向きは問わない）。答えは2〜3文になるので、書く欄は600字まで、録音は60秒まで（ふつうは300字・30秒）。opinion は respond 以外につけると取り込みで止める。採点の決まりは supabase/functions/_shared/graders.ts。
- アナウンスや説明（5つ目の街から）：今までどおり choice4 の audio_text に書く（1人が話すので「A:」はつけない）。30語以上の英文には「▶ ゆっくり聞く」も出す（rules.ts の LONG_AUDIO_WORDS）。
- 記事といくつかの文書（5つ目の街から）：リーディングの sentence の最初の行を「# 見出し」にすると、見出しつきの記事のカードになる。「---」だけの行で区切ると文書ごとに分け、「文書1」「文書2」…の札をつけて並べる（メール・メッセージ・記事・ふつうの文をまぜてよい）。表示は src/components/Passage.tsx。
- エンディング（5つ目の街）：最後の街（rules.ts の FINAL_TOWN_ID = town05）のボスを初めて倒すと、戦闘結果の画面に「～ 旅のおわりに ～」のお知らせを出す。ボスの画面にも「5つの街をめぐる英語の旅を やりとげました」と出る。
- メールとメッセージの見せ方（2026-11-21）：リーディングの sentence の最初が From:・To:・Subject:・Date: の行（2行以上）ならメールのカード（上に差出人・件名などの欄、下に本文）、どの行も「名前: 本文」（名前は1語）ならスマホのメッセージのような吹き出しで出す（components/Passage.tsx）。書き方は今までどおり sentence に改行つきで書く。
- 会話のリスニング（2026-11-21）：audio_text が2行以上なら、どの行も「名前: 英文」の形にする（取り込みで確かめる）。1人目はいつもの声、2人目は性別のちがう声（なければ声の高さを変える）で、1行ずつ読む。答えたあとは1行ずつ出す。

### モンスターファイルの形式

街のモンスターは `data/town01_monsters.json` のように、問題とは別のファイルにする。`town` は問題ファイルと同じ形で、`monsters` に1体ずつ並べる。取り込みは問題と同じ「教材の取り込み」画面で行う。

| 項目 | 内容 |
| --- | --- |
| id | モンスターのID。例：town01-mon-voc |
| name | 名前 |
| skill | 対応する能力値。ボスとめずらしいモンスターは書かない（null） |
| hp、gold | 相手のHPと、倒したときのお金 |
| is_boss、image | ボスかどうか、絵のパス（Pixellab で作った PNG） |
| description | 図鑑の説明文（書かなくてもよい） |
| encounter_rate | めずらしいモンスターだけに書く。街の外の出会いのうち、このモンスターになる割合（0.01 なら1%） |
| exp_reward | 勝ったときの経験値のおまけ（出た能力値で分ける）。書かなければ0 |

### 装備品ファイルの形式

店の品物は `data/town01_equipment.json` のように、街ごとのファイルにする。`town` は問題ファイルと同じ形で、`equipment` に1つずつ並べる。

| 項目 | 内容 |
| --- | --- |
| id | 装備品のID。例：town01-wpn-voc |
| name | 名前 |
| slot | weapon（武器）か armor（防具） |
| effect | 効果。武器は `{"type": "attack", "skill": "vocabulary", "amount": 3}`（語彙の問題で攻撃力+3）。skill を `"all"` にすると、どの能力値の問題でも効く。防具は `{"type": "max_hp", "amount": 1}`（HP+1）か `{"type": "decay_grace", "days": 1}`（低下が始まるまで+1日） |
| price、image | 値段と、絵のパス |

英語の正誤を変える効果（ヒント、選択肢を減らす等）は、取り込みの点検ではねる。

## 技術構成

画面はReact（Vite）、ログイン・記録の保存・サーバー処理はSupabaseで作る。スマホとPCで同じ記録を使うため、自分専用の間もログインを入れる。

| 部分 | 使うもの | 補足 |
| --- | --- | --- |
| 画面 | React（Vite） | 静的サイトとして置く。iPhoneではホーム画面に追加して起動する |
| ログイン | Supabaseの認証 | Google ログイン（はじめての人はそのままアカウントができる）と、メールアドレス＋パスワード。設定は docs/setup_google_login.md |
| データの保存 | Supabaseのデータベース（Postgres） | 利用者ごとに記録を分けるアクセス制限を最初から設定する |
| サーバー処理 | SupabaseのEdge Functions | AI採点と文字起こしの呼び出しを置く。AIサービスの利用キーもここに保管する |
| AI採点と文字起こし | 採点は Claude（claude-haiku-5-5）、文字起こしは OpenAI（gpt-transcribe） | 差し替えできるよう、呼び出しを1か所にまとめる（`supabase/functions/_shared/`） |
| 音声の読み上げ | ブラウザ標準の読み上げ機能 | リスニングの出題に使う |
| 六角形 | レーダーチャート | グラフ用のライブラリを使うか、SVGで自作する |

- Supabaseは無料プランで始める。データベースは500MB、Edge Functionsの呼び出しは50万回まで含まれる。7日間操作がないと一時停止される。有料のProプランは月25ドルから。[Supabaseの料金ページ](https://supabase.com/docs/pricing)で2026年11月15日に確認。
- AIの利用料は使った分だけかかる。安価なモデルを使えば、1日30問の採点で月1ドル未満に収まる試算。
- データの読み書きは1か所にまとめて書く。保存先を変えるときに直す場所が少なくて済む。
- 通信できない場所では練習できない。必要になったら、端末に一時保存して後で送る仕組みを足す。
- AI採点と文字起こしは、ログインした本人だけが呼べるようにする。
- 公開するときは、新規登録を開き、AI採点に利用者ごとの回数制限を足す。利用者が増えたらProプランに移る。

## 開発の進め方

4段階で作る。第1段階だけで「街で準備し、戦って育ち、ボスを倒す」が一通り遊べる状態にする。

1. 第1段階（最小版）：最初の街1つを遊べるようにする。モンスター5種（語彙・文法・リスニング・ライティング・スピーキング）、ボス1体、店1軒。ログインとサーバー保存、六角形、経験値とレベル、お金と装備、能力値の低下、復活モンスター、問題ファイルの取り込みまで入れる。
2. 第2段階：2つ目以降の街と世界地図。リーディングを解放。記録画面、教材の一覧と編集、アプリ内でのAIによる問題作成、称号、入力式や並べ替えなど4択以外の出題形式、データの書き出しを足す。
3. 第3段階：能力値の形に応じた「職業」、装備の種類の追加など、育成の楽しみを増やす。AIと数往復やりとりする会話練習も候補。
4. 第4段階（公開する場合のみ）：誰でも登録できるログイン、AI採点の回数制限、利用規約、教材と絵の権利確認。

第1段階は大きいので、次の順に作る。手順2が終わった時点で、戦って六角形が伸びるところまで遊べる。

1. Supabaseの準備（ログインと保存）。iPhoneのホーム画面から開いた状態で録音できるかを、小さな試作で確かめる。
2. 4択の戦闘（語彙・文法・リスニング）と六角形。絵は仮のもので進める。
3. お金、店、装備。
4. ライティングのAI採点。
5. 録音と文字起こしを足してスピーキング。
6. ボスと復活モンスター。
7. 仮の絵をドット絵に差し替える。

第1段階ができたら1〜2週間実際に使い、経験値や低下の数値を調整してから次へ進む。

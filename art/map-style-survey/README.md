# マップの見え方の調べもの（2026-11-21）

いろいろなゲームのマップの見せ方を7つの種類に分け、それぞれを Pixellab でオリジナルに描いた見本（1〜7.png）。
ほかのゲームの画面そのものではない（raw-*.png は拡大前の絵）。4 は 2〜3 と同じ世界地図の見本を、スクリプトで奥へ傾けたもの。

1. 真上から見下ろす（タイルのマス目）
2. ななめ上から見る（今の English Quest のマップ）
3. 高さのある地形（がけ・段差・階段）
4. 奥へ傾けた世界地図（遠くが小さく、空が見える）
5. 点と道でつなぐワールドマップ（ステージを選ぶ形）
6. クォータービュー（ひし形のマス、段差のある戦略マップ）
7. ドット絵＋立体の舞台（光やぼかしを使う、新しめの見せ方）
